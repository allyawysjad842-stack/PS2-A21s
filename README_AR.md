# PS2 A21s — مشروع تطوير أولي

مشروع Android Studio تجريبي لتطوير نواة C++ مرتبطة بالتطبيق عبر JNI، مع مسار بناء سحابي APK عبر GitHub Actions يمكن تشغيله من الهاتف.

## ما الموجود الآن؟
- واجهة Android باسم PS2 A21s.
- مكتبة C++ native تُبنى باستخدام Android NDK وCMake.
- نموذج CPU صغير جدًا يختبر ثلاث تعليمات فقط: `ADDIU`, `ORI`, `LUI`.
- اختبار ذاتي يظهر داخل التطبيق.
- Workflow لبناء APK debug في GitHub Actions.

## مهم جدًا
**هذا ليس محاكي PS2 جاهزًا، ولا يشغّل ألعاب PS2.** إنه أساس برمجي لاختبار خط البناء والربط الأصلي. بناء محاكي كامل يتطلب تنفيذ مكونات PS2 المعقدة واختبارات توافق واسعة.

## البناء من الهاتف
اتبع `BUILD_FROM_PHONE_AR.md` لرفع الملفات إلى GitHub وتشغيل Workflow ثم تنزيل APK الناتج.
